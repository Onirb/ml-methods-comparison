The original notebook, now preserved as `notebooks/Assignment_legacy.ipynb`,
was executed linearly from a temporary copy on **19 November 2026**. The
tracked notebook was not modified during reproduction.

- Platform: Windows 11, Python 3.12.10
- Result: complete execution, exit code 0
- Notebook: 77 cells, 51 code cells
- Executed code cells: 49; two code cells contain no executable work
- Saved outputs in the clean run: 29
- Cell errors: 0
- Approximate wall time: 12 minutes
- Peak observed working set: approximately 1.3 GB

The compatibility environment is specified in `requirements-legacy.txt`. The
key constraint is scikit-learn 1.3.2, which still accepts the notebook's legacy
`base_estimator` argument. IPython 8.37.0 is also pinned because the newest
IPython was incompatible with the selected historical Matplotlib interface.

## Interpretation

Successful execution establishes that the code path can still run. It does not
validate the original methodology. Several stochastic outputs differ from the
outputs stored in the notebook because parts of the historical code do not
control randomness locally. The temporary clean execution did not generate the
three PNG files currently tracked under `results/`; those artifacts therefore
cannot be claimed as regenerated by this run.

The original notebook remains historical evidence. New portfolio results must
come from the table-driven modern implementation and must not overwrite or be
presented as a bit-for-bit reproduction of the legacy conclusions.
